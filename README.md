# Ferme de Treslemont — site vitrine (maquette)

Maquette de site professionnel pour la **Ferme de Treslemont** (Babeth & Jean-Luc Margerit,
125 chemin de Treslemont, 43200 Yssingeaux, Haute-Loire), producteurs de yaourts, faisselles, crèmes et
fromages fermiers de vache et de chèvre.

Site statique (HTML / CSS / JS, sans dépendance ni compilation). Navigation **horizontale** en 6 pages :

| # | Page | Contenu |
|---|------|---------|
| 01 | Accueil | Accroche, présentation, chiffres clés |
| 02 | La ferme | Histoire, troupeau, pratiques (désherbage mécanique, homéopathie, huiles essentielles), repères |
| 03 | Nos produits | Yaourt nature primé, yaourts, faisselles, petit rond de Treslemont, fromages, crème |
| 04 | Où nous trouver | Distributeur à la ferme, marchés, carte schématique |
| 05 | Visites & gîte | Visites sur réservation, gîte Gîtes de France (7 pers., 110 m²) |
| 06 | Contact | Coordonnées, formulaire (ouvre la messagerie) |

On change de page avec le menu, les flèches en bas, les touches ← → du clavier, ou en glissant
le doigt sur mobile. Chaque page a sa propre adresse (`#produits`, `#contact`…).

## Voir le site

- En local : ouvrir `index.html` dans un navigateur.
- En ligne : **Settings → Pages → Build and deployment → Source : « Deploy from a branch »,
  branche `main`, dossier `/ (root)`**. Le site sera publié sur
  `https://<utilisateur>.github.io/ferme-du-treslemon-website/`.

  04 71 48 64 21) ; seul le portable 06 08 43 77 87 est affiché pour l'instant.
- **Marché de Brives-Charensac** : jour non trouvé. Les marchés de Monistrol (samedi) et
  Brives n'apparaissent pas sur toutes les fiches ; à confirmer.
- **Troupeau** : une source parle de 35 vaches et 120 brebis, les autres de vaches et chèvres.
  Le site retient « vaches et chèvres ».
- **Horaires du distributeur** et liste exacte des produits / prix.
- **Photos** : les illustrations sont des dessins vectoriels provisoires. Il faudra les
  remplacer par de vraies photos de la ferme, du troupeau, des produits et du gîte.
- Mentions légales, SIRET (EARL Domaine de Treslemont), nom de domaine.
